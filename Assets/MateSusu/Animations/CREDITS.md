# Animation credits

Third-party humanoid animations used for Susu's gestures. All files are imported as
Unity Humanoid and played through `SusuClipPlayer`.

## Quaternius/
- **Universal Animation Library 2 (Standard)** by Quaternius — https://quaternius.com
- License: CC0 1.0 Universal (public domain).

## Rokoko/
- **Rokoko Free Mocap Assets (263 pack)** by Rokoko — https://www.rokoko.com/resources/download-263-rokoko-motion-capture-assets
- Rokoko states these free assets can be used in any project, including commercial ones.
  All rights to the original motion data remain with Rokoko.

- Terms: free for commercial and non-commercial use, modification and redistribution, as long as you do not
  claim the work as your own or use it to defame others. Credit to アンテナショップ【ねここや】 with a Booth link is requested.
- Used: `01_Emote_tefuri1`, `02_Emote_tefuri3`, `03_Emote_peace1`, `04_Emote_hawawa`, `05_Emote_umauma_OneLoop`,
  `06_Emote_yoshi`, `07_Emote_Kakapo-Normal_OneLoop`, `08_Emote_CossackDance` (Unity humanoid `.anim`).

## VRSuya/ (not in the repository)
- **Doodle Dance** by VRSuya. Its user agreement allows personal use only and forbids redistributing the data
  (original or modified) without permission and using it in commercial games/videos, so this folder is listed in
  `.gitignore` and stays on the owner's machine. The `doodle` motion is skipped automatically where the file is missing.
